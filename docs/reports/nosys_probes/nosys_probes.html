Probes without the system prompt

Contrastive probes are trained on responses written under a sycophantic or a non-sycophantic system prompt, and until now the activations were taken with that system prompt still in context. We removed it from the forward pass, kept the responses, and retrained.

Methods

  1. Data. The tefo contrastive set: 640 prompts, 14 system-prompt pairs (8 taxonomy cells, the baseline, 5 controls), one sycophantic and one non-sycophantic response per prompt and pair, 17,920 rows. The responses were generated earlier with the system prompt; they are reused unchanged.
  2. Two contexts. With system prompt: the prompt the response was written under. Without: the system message removed; Llama 3.1's template then adds its default block (“Cutting Knowledge Date … Today Date …”), exactly as for the benchmark rows. Without it, both sides of a pair see token-identical prompts.
  3. Activations. One bfloat16 forward pass per row and context on an A100 (interp/cache_activations.py, --drop-system-prompt for the second). Mean over response tokens and the last prompt token, all 32 blocks, stored in float16, with each row's mean response NLL and next-token agreement from the same pass.
  4. Probes. Per pair: logistic regression (C ∈ {1e-4 … 10}) and difference of means, at blocks 3, 6, 10, 13, 16, 19, 22, 26, 29. One split by prompt for every pair and both contexts: 448 train, 64 validation, 128 test prompts, the same split as the earlier sweep. Logistic C is chosen per pair and block on validation AUROC; ties go to the smaller C. Test numbers are on test prompts only.
  5. Benchmarks. Sampled Llama 3.1 responses (T 0.6, top-p 0.9) to ELEPHANT AITA-YTA, OEQ and SS (validation, indirectness, framing), AITA-NTA-OG, AITA-NTA-FLIP (flipped telling) and Are You Sure, labelled by Sonnet 5.5, with units as in interp/generalization_matrix.py. Both probe sets are scored on the same cached activations. 95% intervals at block resample prompt groups 1,000 times.

6. Checks

Parity with the earlier pipeline. The with-system cache against the September float32 activations (get_activations) of the same rows, and the probes retrained from the cache against the earlier sweep on the same split and grid.

Null check. Without the system prompt, both sides of a pair share a token-identical prompt, so their last-prompt-token vectors should be identical and carry no label. The spread column is the largest distance of a row's vector from its prompt's mean, relative to that mean; the AUROC columns are probes trained on that position with the same grid and split (test prompts).

Limitations

  • One response set, one model. All numbers are for Llama-3.1-8B-Instruct on the tefo set with seed-0 split. Seed-to-seed variance of the split was not measured, so small differences between the two contexts are not interpretable.
  • The responses are off-policy without the system prompt. Section 2 shows the likelihood of the response alone separates the two sides strongly for some pairs. A probe trained without the system prompt can use that signal; this analysis does not remove it.
  • Benchmark labels come from one judge. Sonnet 5.5 labels, without human validation; benchmark AUROC is bounded by label quality. SyPR is not included.
  • Intervals are per AUROC, not per difference. Non-overlapping intervals are a conservative reading of a difference; overlapping ones do not show equality.
  • Batching leaks a little label information into prompt positions. Section 6: identical prompts do not give exactly identical vectors, and a few null probes rise above chance. The in-distribution signals in section 1 are far larger; whether the same noise moves benchmark AUROC by a few thousandths was not measured.

Assumptions

  • Removing the system message keeps Llama 3.1's default system block, so the training prompt matches the benchmark prompt token for token.
  • The training responses are the existing ones, generated through OpenRouter with the system prompt (providers DeepInfra, Novita and Groq, not pinned). The 8 truncated rows are kept, as in the earlier sweep.
  • Probes use the response mean. The last prompt token is cached only as a null check.
  • Layers, C grid, methods, split fractions and seed match the earlier with-system sweep (synthetic_tefo_C_sweep); both contexts are retrained from the new cache so they share one pipeline.
  • Logistic C is chosen on validation AUROC, ties to the smaller C; every block is shown; nothing is chosen on test or benchmark rows.
  • Benchmarks are the sampled set (T 0.6, top-p 0.9) with Sonnet 5.5 labels; units and exclusions follow interp/generalization_matrix.py (AITA-NTA-FLIP on its flipped telling; Are You Sure rows without a defined flip excluded).
  • Training activations are float16 in the cache; earlier sweeps used float32. The parity table bounds the difference.
